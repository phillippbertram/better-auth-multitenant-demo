# Contributing

Thanks for improving the example.

## Local workflow

1. Fork the repository and create a focused branch.
2. Follow the setup in [README.md](README.md).
3. Keep authentication and authorization checks on the server.
4. Run the full project check:

   ```bash
   pnpm check
   ```

5. Open a pull request that explains the user-visible outcome and any security
   implications.

Please keep changes small, avoid unrelated formatting churn, and update the
README when setup or behavior changes.
