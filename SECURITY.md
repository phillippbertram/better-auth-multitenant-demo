# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting or security advisory feature for
this repository. Include the affected flow, reproduction steps, and potential
impact. Avoid sharing real credentials, session cookies, one-time codes, or
personal data.

This example does not include production email delivery, secret management,
rate limiting, monitoring, backups, or data-retention policies. Add them before
using it with real accounts.
