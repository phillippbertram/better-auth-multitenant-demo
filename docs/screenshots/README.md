# README screenshots

These images document the seeded Acme Studio demo and should be refreshed when the navigation, team workflow, note cards, or role matrix changes materially.

## Reproduce the states

1. Start PostgreSQL, apply migrations, and restore the demo scenario with `pnpm db:seed:demo`.
2. Sign in as `sam@example.com` using the shared demo password from the root README.
3. Capture desktop views at approximately 1440 × 900 and the mobile view at approximately 390 × 844.
4. Use the following states:
   - `notes-workspaces.jpg`: Acme Studio with **All organization notes** active;
   - `team-management.jpg`: Acme Studio organization settings on **Teams**;
   - `roles-and-permissions.jpg`: Acme Studio organization settings on **Roles & permissions**;
   - `mobile-team-workspace.jpg`: Acme Studio with the **Marketing** team active.

Keep screenshots free of real user data, browser chrome, and development overlays. Preserve the existing filenames so README links remain stable.
